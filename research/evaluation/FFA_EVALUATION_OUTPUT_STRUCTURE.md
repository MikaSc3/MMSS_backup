# FFA Evaluation Output Structure

This document describes the organized folder structure generated by the FFA evaluation pipeline.

## Top-Level Structure

```
evaluation_results/
├── metrics/                    # JSON metrics files
├── visualizations/             # Global visualizations (all assemblies)
│   ├── confusion_matrices/     # Confusion matrices for all fields
│   ├── f1_scores/              # F1-score bar charts and comparisons
│   └── step_analysis/          # Step-by-step evaluation analysis
└── per_assembly/               # Per-assembly breakdown
    └── <Assembly_Name>/
        ├── visualizations/     # Assembly-specific visualizations
        │   ├── confusion_matrices/
        │   └── f1_scores_per_field.png
        └── step_analysis/      # Assembly-specific step analysis
```

## Folder Descriptions

### `metrics/`
Contains all JSON metric files with quantitative evaluation results:
- **metrics_summary.json**: Overall aggregated metrics across all fields and assemblies
- **metrics_per_field.json**: Detailed metrics for each of the 14 FFA fields
- **metrics_per_subprocess.json**: Aggregated metrics for the 4 subprocesses (separation, handling, positioning, joining)
- **metrics_per_assembly.json**: Performance breakdown for each assembly

### `visualizations/`
Global visualizations combining data from all assemblies:

#### `visualizations/confusion_matrices/`
Confusion matrix heatmaps for each field across all assemblies:
- Format: `all_assemblies_<subprocess_number>_<subprocess>_<field>_cm.png`
- Example: `all_assemblies_2_Handling_handling_gripping_areas_cm.png`
- Shows predicted vs ground truth classifications

#### `visualizations/f1_scores/`
F1-score and accuracy comparison charts:
- **all_assemblies_f1_scores_per_field.png**: Bar chart of F1-scores for all 14 fields
- **all_assemblies_f1_scores_per_subprocess.png**: Comparison across 4 subprocesses
- **comparison_across_assemblies.png**: Performance comparison between assemblies

#### `visualizations/step_analysis/`
Step-by-step evaluation analysis across all assemblies:
- **step_by_step_evaluation.json**: Detailed field-level comparison for every assembly step
- **step_by_step_evaluation.xlsx**: Excel report with color-coded cells (green=match, red=mismatch)
- **step_accuracy_heatmap.png**: Matrix visualization (rows=steps, columns=fields)
- **field_accuracy_summary.png**: Stacked bar chart showing correct/incorrect/missing counts per field

### `per_assembly/`
Per-assembly breakdown with individual metrics and visualizations:

Each assembly has:
- **visualizations/confusion_matrices/**: Assembly-specific confusion matrices
- **visualizations/f1_scores_per_field.png**: F1-score bar chart for this assembly only
- **step_analysis/**: Step-level evaluation specific to this assembly
  - **step_accuracy_heatmap.png**: Steps × Fields heatmap for this assembly
  - **field_accuracy_summary.png**: Field accuracy breakdown for this assembly

## File Naming Conventions

### Confusion Matrix Files
- Global: `all_assemblies_<SUBPROCESS_PREFIX>_<field_key>_cm.png`
- Per-assembly: `<SUBPROCESS_PREFIX>_<field_key>_cm.png`

Example: `all_assemblies_2_Handling_handling.gripping_areas_cm.png`

### Field Keys
Fields are referenced as `subprocess.field_name` throughout the pipeline:
- `separation.nature_of_provision`
- `handling.part_rigidity`
- `handling.gripping_areas`
- `positioning.accuracy_of_target_position`
- `joining.feeding_of_joining_element`

### Subprocess Prefixes
- Separation: `1_Separation`
- Handling: `2_Handling`
- Positioning: `3_Positioning`
- Joining: `4_Joining`

## Data Flow

1. **Input**: Ground truth + LLM predictions (enum-encoded)
2. **Step Matching**: Pair GT and predictions by assembly and step_id
3. **Metrics Calculation**:
   - Per-field: Accuracy, Precision, Recall, F1-Score
   - Aggregated: Overall mean/weighted metrics
   - Per-subprocess: Aggregate across fields in each subprocess
   - Per-assembly: Assembly-level performance metrics
4. **Visualizations**: Generate confusion matrices, bar charts, heatmaps
5. **Output**: Organized folder structure with all results
